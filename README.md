# 담보 대출 한도 확인

부동산 담보로 받을 수 있는 예상 대출금액을 계산하는 웹페이지입니다. 담보 기준 한도, 수도권·규제지역 금액 상한, DSR 한도 중 가장 작은 값을 보여주고 어떤 조건 때문에 정해졌는지 표시합니다.

```
담보 기준 한도 = 시가 × min(낙찰가율, LTV) − 소액임차보증금(호수 × 지역별 최우선변제금)
예상 대출가능금액 = min(담보 기준 한도, 가격 구간·목적 상한, DSR 한도)
예) 1억 × min(70%, 70%) − 2,500만원(그 밖의 지역 주택 1호) = 4,500만원
```

## 파일

- `index.html`: 계산기 화면 (브라우저에서 바로 열면 됨)
- `loanRules.js`: 대출 규제 수치와 규제지역 목록. 정책이 바뀌면 이 파일만 고치면 됨
- `loanLimit.js`: 한도 계산 함수 (LTV, 가격 구간 상한, DSR, 대출 불가·경고 조건)
- `tests/loanLimit.test.js`: 계산 테스트 (`npm test` 또는 `node --test tests/loanLimit.test.js`)
- `data/auction_rates.csv`, `data/auction_rates.json`: 시도 × 용도 매각가율 표
- `data/trades.js`, `scripts/fetch_trades.py`: 아파트 실거래가 표와 이를 만드는 스크립트 (아래 '실거래가 받기')
- `scripts/build_rates.py`: 법원경매정보 '용도별 매각통계' 엑셀로 위 표를 다시 만들고 `index.html` 데이터도 갱신

## 데이터 기준

- 법원경매정보 용도별 매각통계, 시도별, 2021.10~2026.09 (1년 단위 5개 기간)
- 기간별 매각가율 = 매각가 합계 ÷ 감정가 합계 (3년·5년은 최근 1년 포함)
- 적용 낙찰가율 = max(5년 매각가율, 최근 1년 50% + 3년 30% + 5년 20% 가중평균)
- 기간마다 지역 매각이 30건 미만이면 같은 지역 상위 분류 소계, 그것도 부족하면 같은 기간 전국 값(시도 합계) 사용
- 강원(강원도+강원특별자치도), 전북(전라북도+전북특별자치도), 광주전남(광주+전남+전남광주)은 합산
- 대출 규제(2025.6.27·10.15 대책, 2026.6.30 규제지역 추가, 2026.10 기준): 규제지역은 서울 전역과 경기 15곳. LTV는 규제지역 40%, 비규제 수도권 70%, 지방 70%(생애최초 수도권 70%·지방 80%). 수도권·규제지역에서는 다주택자와 처분조건 없는 1주택자의 주택구입 대출 불가, 주택구입 상한 6억/4억/2억, 이주비 6억, 생활안정자금 1억(2주택 이상 불가). DSR 은행 40%·비은행 50%, 스트레스 금리 수도권·규제지역 3.0%·지방 0.75%(혼합형 80%·주기형 40%·고정 0% 반영). 지방 다주택 LTV 60%. 디딤돌·보금자리론은 소득·주택가격 요건과 상품 자체 한도 적용, DSR 제외. 자세한 값은 `loanRules.js`
- 선순위 채권(기존 근저당 채권최고액)은 담보 기준 한도에서 차감

## 화면 기능

- DSR이 한도를 정하면 '한도를 늘리려면' 역산 제안(필요 연소득, 최장 만기, 고정금리, 기존 대출 상환, 비은행)
- 최종 한도 기준 월 상환액
- 계산 조건이 주소(#) 뒤에 저장되어 링크로 공유 가능
- 인쇄·PDF 저장 시 산정표를 먼저 한 열로 출력
- 규정 기준일(`effectiveDate`)에서 6개월이 지나면 확인 경고
- 최우선변제금은 주택·상가건물 임대차보호법 시행령의 지역별 금액. 차감액은 예상 낙찰가의 1/2을 넘지 않음

## 실거래가 받기 (선택)

아파트 실거래가를 미리 받아 두면 시세 칸 아래 '실거래가로 채우기'에서 단지·전용면적별 최근 12개월 중위가와 최근 거래가를 골라 넣을 수 있습니다.

1. 공공데이터포털(data.go.kr)에서 '국토교통부_아파트 매매 실거래가 상세 자료' 활용신청 → 일반 인증키(Decoding) 복사
2. 실행 (코드를 주지 않으면 서울 25개 구, 경기 등은 `코드=이름`으로 지정)

```
python scripts/fetch_trades.py --key <인증키>
python scripts/fetch_trades.py --key <인증키> 11680 11650 41135=성남시분당구 41463=용인시기흥구
```

결과는 `data/trades.js`에 저장됩니다(표준 라이브러리만 사용, 해제 거래 제외). 인증키는 파일에 저장되지 않습니다.

## 표 다시 만들기

```
pip install xlrd
python scripts/build_rates.py <2021.10~2022.09 폴더> <2022.10~2023.09 폴더> <2023.10~2024.09 폴더> <2024.10~2025.09 폴더> <2025.10~2026.09 폴더>
```

참고용 추정치이며 실제 대출 한도는 금융회사 규정과 감정평가 결과에 따라 달라집니다.
